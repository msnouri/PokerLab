What the books actually supplied

I extracted the text from all four attachments, identified their contents and reviewed the relevant instructional sections. The numerical policies are original experimental approximations inspired by those concepts. They are not 80 complete author-prescribed strategies, and no claim is made that these implementations reproduce the authors' full play.

The 80 candidates

Each family has five variants. Relative to its central variant, the variants change preflop opening width, value thresholds, calling margin and bet size; eligible bluff frequencies and tournament risk margins also change. This structured sweep tests packages of parameters, so it cannot attribute a result to a single parameter. All numerical settings are in strategies.csv.

Experimental design

  1. Direct self-play: all 80 candidates play 500 hands each (40,000 player-hands; 5,000 table-hands). Random groups of eight are redrawn every eight hands; seats rotate across the block. Stacks reset to 2,000 each hand, with blinds 10/20.
  2. Matched gauntlet: each candidate plays 500 hands against the same seven baseline policies (40,000 table-hands). All candidates use the same 500 shuffled deals. The candidate rotates seats; each seat occurs 62 or 63 times. Opponents cannot see the candidate's identity or cards.
  3. Fresh validation: the top eight from each initial test plus the best representative of each family produce 25 unique candidates. Each plays 2,000 new matched gauntlet hands (50,000 table-hands). These results select eight tournament finalists, so this phase is model selection, not untouched final confirmation.
  4. Tournaments: finalists play persistent-stack sit-and-gos against three baseline fields, for 3,072 tables and 529,966 table-hands. Starts: 2,000 chips, blinds 10/20. Big blinds: 20,30,40,60,100,150,200,300; levels last 25 hands; cap 200 hands. Assumed points: 50/30/20 for the top three. Survivors at the cap receive exact ICM expected points for the remaining finishing places. Simultaneous eliminations use starting-hand stacks, splitting exact ties.

Deck, policy randomization and equity-sampling seeds are separate. Only hole cards belonging to the acting player, exposed board cards, legal bet bounds and public action statistics enter the policy. PokerKit handles game legality and settlement. Every simulated hand checks chip conservation. Invalid agent actions raise errors rather than silently becoming valid actions.

What the agent computes

Preflop: a 169-class table, generated with 4,000 seeded deals per class against one through seven uniformly random opponents. Opening percentiles weight the 1,326 distinct two-card combinations. Postflop: 48 sampled runouts and opponent holdings, excluding the player's cards and public board, with a weak smoothing prior. Draw, board texture, position, pot odds, stack depth and public betting pressure modify decisions.

This is a family of heuristic agents. The postflop estimator does not infer full conditional opponent ranges, and the polarized policy is not a GTO solution. Continuation betting, semi-bluffing and trapping are simple rules rather than multi-street search. ICM is exact for cap scoring; decisions use a small risk-margin approximation rather than full ICM action optimization. Opponent models see within-hand actions in reset-stack tests, and accumulate only within a table in tournament tests.

Competition fit and remaining work

This is a working research bot, not a verified event submission. The official event reveals its variant and Agent interface at the build phase. Ordinary two-card no-limit Hold'em, the full blind schedule and the 50/30/20 payout are our stated research assumptions.

The official rules describe eight-bot sit-and-gos, a 200-hand cap, 2,000-chip starts, 10/20 starting blinds and 25-hand levels. They require isolated offline bots and decisions within 1 ms. They score finishing position and ICM, rather than cash-style chip profit. The event has a 60-minute build phase. See the official rules, sections 3-4. The homepage currently marks applications closed.

Before entering a similar event: plug in its actual rules, payout schedule and SDK; adapt card evaluation if the variant changes; measure latency inside its sandbox; replace random-hand equity with a stronger public-action-conditioned range model; and confirm the chosen policy on untouched seeds and unfamiliar opponents. No participant repository was copied. The project uses general-purpose open-source PokerKit and eval7 dependencies.

Run it yourself

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python -m pokerlab.experiment --stage all --hands 500 --validation-hands 2000 --tables 128 --workers 8
python -m pokerlab.analyze
python -m pokerlab.bot < example_observation.jsonl

The JSON-lines bot defaults to S55. Choose any candidate with --strategy S01 through --strategy S80. Its input schema is the Observation dataclass in pokerlab/agent.py. This neutral interface must be mapped to the competition SDK.

Deliverables and audit trail

  • strategies.csv: all 80 policies and exact parameters.
  • pokerlab/: source, simulation runner, equity asset generator, analysis and JSON bot.
  • results/*_hands.csv and tournament_tables.csv: per-hand or per-table outcomes, seeds and seats.
  • results/tournament_overall.csv and paired_tournament_comparisons.csv: rankings and uncertainty.
  • tests/test_core.py: eight tests covering registry uniqueness, equity sanity, determinism, privacy, independent evaluator agreement, exact side pots/ties, ICM and all strategies on unequal short stacks.
  • results/manifest.json: configuration, software versions and source hashes. Absolute wall times and latency are host dependent; decision outcomes are seeded.

General-purpose repositories: PokerKit, eval7, and Treys (independent evaluator tests only). Dependency licenses are recorded in THIRD_PARTY_NOTICES.txt. The package does not include the uploaded books or their extracted full text.

Interpretation: these tests compare our implementations in a documented synthetic environment. They cannot establish which book is best, whether a strategy is unexploitable, or whether it will win a competition.
